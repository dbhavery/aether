Customer Assistant Demo

Ask our assistant anything about your order.

This page is a stand-in for a company's website. The chat bubble in the bottom-right corner is a drop-in widget powered by the Aether Customer Assistant — a per-company, knowledge-grounded support assistant running entirely on your machine.

Try asking:

  • "How long do I have to return something?"
  • "What are my shipping options and how much do they cost?"
  • "Are your rain jackets actually waterproof?"
  • "My package is lost." (triggers escalation to a human)
  • "How do I file a warranty claim?"

How it's embedded

The entire widget is one script tag — it themes itself from the company's company.yaml branding: 

<script
  src="http://127.0.0.1:8200/widget.js"
  data-company="northwind-outdoors"
  data-api="http://127.0.0.1:8200"
  defer></script>

Note: if Ollama isn't running, the assistant still answers using the retrieved help-center articles (you'll see an "offline" note) so the demo always works.
