# Code of Conduct

The Free Aether — Community Edition project adopts the **Contributor Covenant, version 2.1**, as its code of conduct for all project spaces: the GitHub repository, issue tracker, pull-request discussions, and any future project forums.

- Canonical text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Plain-text reference: https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt
- License of the covenant text: Creative Commons Attribution 4.0 International.

By participating in this project — opening issues, commenting, submitting pull requests, or engaging in any project channel — you agree to follow the Contributor Covenant v2.1 as linked above.

## Scope

The Code of Conduct applies within all project spaces, and also applies when an individual is officially representing the project in public. Representation includes using an official project email address, posting via an official social media account, or acting as an appointed representative at an online or offline event.

## Reporting

If you experience or witness behavior that violates the Code of Conduct, please report it privately via one of the following channels:

- **GitHub Security Advisories (preferred):** use the "Report a vulnerability" / "Private vulnerability reporting" flow on this repository. This is a private channel and is also used for security reports (see `SECURITY.md`).
- **Direct contact:** open a private issue report by DMing the maintainer `@dbhavery` on GitHub.

Reports will be reviewed by the project maintainer. Confidentiality will be respected to the extent possible while still allowing the report to be acted on.

Project maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent repercussions as determined by the project's leadership.

## Enforcement

The maintainer will determine the consequences of any action deemed in violation of this Code of Conduct, using the enforcement guidelines published alongside the Contributor Covenant v2.1:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

Possible outcomes include private warnings, public warnings, temporary bans from project spaces, and permanent bans — calibrated to the severity and pattern of the behavior.
