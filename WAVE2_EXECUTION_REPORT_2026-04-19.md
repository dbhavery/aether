## 2. Package structure actually implemented

### 2.1 `packages/l5-policy` (Rust)

Flat module layout — one concern per file, re-exported from `lib.rs`:

```
src/
├── lib.rs            public surface + module doc comments + invariants list
├── common.rs         newtype ids (RequestId, ChangeId, AuditIdString, ...),
│                     Cents, MonotonicTimestamp / WallTimestamp, ActorRef, CommandToken
├── capability.rs     Capability (all 7 groups + Decision 3 additions), IntegrationId,
│                     ApiId, AutomationId, CapabilityPath, ResourceScope, CapabilityFilter,
│                     CapabilityInfo, RiskClass, ProvenanceTag
├── decision.rs       Decision (5 top-level variants incl. NeedsUpgrade),
│                     DraftSource, DecisionKind, DenyReason, HardcodedBlockId,
│                     TaintKind, StaticReasonId, ReEvalTrigger (8) + ALL const
├── approval.rs       ApprovalTicket, ApprovalTicketId, ApprovalResponse, UserChoice
├── grants.rs         Grant, GrantId, GrantDuration, ApprovalMode, GrantFilter,
│                     GrantLedger trait, PersonaCompiledPolicyDefaults
├── audit.rs          AuditId, KeyId, StageTrace, AuditRecordEvent, AuditFilter, AuditSummary
├── events.rs         L5Event (9 variants), L5EventKind, plus each per-event struct;
│                     EmergencyScope, RevokeReason
├── ipc.rs            PolicyCommands trait (16 methods), PolicyIpcError,
│                     AuditExportFormat, ExportUri, ApprovalReceipt, PresetSwitchReceipt,
│                     CurrentPreset, RevokeTarget, RevokeReceipt, EmergencyReceipt,
│                     Explanation, PlanPreview, StreamCursor
├── policy_engine.rs  PolicyEngine trait (6 methods), PolicyEngineError, ActionRequest,
│                     RouteHint, EventFilter, EventStream<T>, EmergencyReceipt (in-process)
├── byok.rs           ProviderId, CostWindow, CostThreshold, CostCap, CostEvent
├── posture.rs        PrivacyPosture, PolicyPostureSummary, PostureTrigger,
│                     DegradedMode, WarnLevel
└── storage_hooks.rs  GrantStore, AuditStore, CostCounterStore traits;
                      AuditWriteError, AuditVerifyError
tests/
└── smoke.rs          7 shape-only assertions; no logic
```

**Dependencies:** `thiserror`, `serde`, `serde_json`, `tracing` (workspace-pinned) plus path-deps on `aether-event-bus`, `aether-storage`, `aether-telemetry`. No SQLite driver, no tokio runtime, no `ts-rs` — those arrive with the generator and persistence waves.

**Intentional omissions:**
- No `handle_evaluate`, `write_audit_row`, or any method body beyond trivial enum helpers.
- No Tauri `#[tauri::command]` wiring; handlers live in `apps/desktop/src-tauri/` (not scaffolded yet).
- No `ts-rs` derives — generator not ready.
- `PolicyEngine::subscribe` returns a placeholder `EventStream<T>` struct with `PhantomData`; Wave 3 swaps in `tokio::sync::broadcast`.

Because L5 shapes are stable, a parallel early-stub wave for the other layer crates is now practical. Each layer can:
